# 下单参数速查表

## 按 FrpCode 分类的必填参数速查

### 微信渠道

| FrpCode | 基础必填 | 渠道必填 | 响应说明 |
|---------|---------|---------|---------|
| WEIXIN_NATIVE | p1/p2/p3/p4/p5/q1/p9/hmac | q4_IsShowPic(可选) | rc_Result为二维码URL，⭐推荐用前端qrcode.js等库转二维码图片；q4_IsShowPic=1时返回rd_Pic(⚠️base64可能含换行符导致裂图) |
| WEIXIN_GZH | p1/p2/p3/p4/p5/q1/p9/hmac | **q5_OpenId** + **q7_AppId** | JSAPI调起支付参数 |
| WEIXIN_XCX | p1/p2/p3/p4/p5/q1/p9/hmac | **q5_OpenId** + **q7_AppId** | wx.requestPayment参数 |
| WEIXIN_APP | p1/p2/p3/p4/p5/q1/p9/hmac | **q7_AppId** | APP调起支付参数 |
| WEIXIN_APP3 | p1/p2/p3/p4/p5/q1/p9/hmac | **q7_AppId**(报备小程序) | APP跳转小程序 |
| WEIXIN_H5 | p1/p2/p3/p4/p5/q1/p9/hmac | - | 跳转支付URL |
| WEIXIN_H5_PLUS | p1/p2/p3/p4/p5/q1/p9/hmac | **q7_AppId**(报备小程序) | 跳转小程序 |
| WEIXIN_CARD | p1/p2/p3/p4/p5/q1/p9/hmac | **q6_AuthCode** + **q8_TerminalNo** + **ql_TerminalIp** | 直接返回支付结果 |

### 支付宝渠道

| FrpCode | 基础必填 | 渠道必填 | 响应说明 |
|---------|---------|---------|---------|
| ALIPAY_NATIVE | p1/p2/p3/p4/p5/q1/p9/hmac | - | rc_Result为二维码URL，⭐推荐用前端qrcode.js等库转二维码图片 |
| ALIPAY_H5 | p1/p2/p3/p4/p5/q1/p9/hmac | q9_TransactionModel(可选) | 跳转支付URL |
| ALIPAY_APP | p1/p2/p3/p4/p5/q1/p9/hmac | - | APP调起支付参数 |
| ALIPAY_FWC | p1/p2/p3/p4/p5/q1/p9/hmac | **qb_buyerId**(2088开头) | 服务窗支付 |
| ALIPAY_CARD | p1/p2/p3/p4/p5/q1/p9/hmac | **q6_AuthCode** + **q8_TerminalNo** + **ql_TerminalIp** | 直接返回支付结果 |

### 银联渠道

| FrpCode | 基础必填 | 渠道必填 | 响应说明 |
|---------|---------|---------|---------|
| UNIONPAY_NATIVE | p1/p2/p3/p4/p5/q1/p9/hmac | - | rc_Result为二维码URL链接，可直接转二维码图片 |
| UNIONPAY_H5 | p1/p2/p3/p4/p5/q1/p9/hmac | p8_ReturnUrl(推荐) | 跳转支付URL |
| UNIONPAY_APP | p1/p2/p3/p4/p5/q1/p9/hmac | - | APP调起支付参数 |
| UNIONPAY_CARD | p1/p2/p3/p4/p5/q1/p9/hmac | **q6_AuthCode** + **q8_TerminalNo** + **ql_TerminalIp** | 直接返回支付结果 |
| UNIONPAY_WXMP | p1/p2/p3/p4/p5/q1/p9/hmac | **qm_ContractId**(签约ID) | 云微小程序支付 |

## 报备商户号

`qa_TradeMerchantNo`（报备商户号）为必填参数，在商户后台「报备管理」中获取。
