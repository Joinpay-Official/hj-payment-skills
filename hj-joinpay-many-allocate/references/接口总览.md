# 延迟分账与多次分账接口总览

延迟分账和多次分账使用独立 JSON 协议，统一入口为 `/allocFunds`。文档给出的生产地址为 `https://www.joinpay.com/allocFunds`。

## 公共请求

| 参数 | 说明 |
|------|------|
| `method` | 接口方法名，如 `altHandle.singleLaterAllocate`、`altHandle.manyLaterAllocate` |
| `version` | 接口版本，当前文档主版本使用 `1.1` |
| `data` | 业务参数 JSON |
| `rand_str` | 32 位随机串 |
| `sign_type` | `1`=MD5，`21`=RSA |
| `mch_no` | 商户编号 |
| `sign` | 请求签名 |

## 接口列表

| 接口 | method | 用途 | 核心请求字段 | 响应重点 |
|------|--------|------|--------------|----------|
| 单次延迟分账请求 | `altHandle.singleLaterAllocate` | 对延迟分账订单发起一次分账 | `mch_order_no`、`alt_order_no`、`alt_info`、`callback_url` | `resp_code`、`alt_main_status`、`biz_code` |
| 延迟分账查询 | `altHandle.allocateQuery` | 按分账订单号查询单次延迟分账结果 | `alt_order_no` | 分账明细、主状态、金额 |
| 多次分账请求 | `altHandle.manyLaterAllocate` | 发起一次延迟分账 | `mch_order_no`、`alt_order_no`、`alt_this_amount`、`alt_info`、`callback_url` | `resp_code`、`alt_main_status`、`biz_code` |
| 完结分账 | `altHandle.finishAllocate` | 将订单剩余金额归平台，不再继续分账 | `mch_order_no`、`alt_order_no`、`callback_url` | `resp_code`、`alt_main_status`、`biz_code` |
| 查询单笔分账 | `altHandle.altManyOrderQuery` | 查询某一笔分账订单 | `alt_order_no` | 分账明细、主状态、金额 |
| 查询所有分账 | `altHandle.altManyTotalQuery` | 查询支付订单维度的全部分账和剩余金额 | `mch_order_no` | `alt_detail_info`、`alt_remain_amount`、`alt_remain_fee`、`alt_remain_transit_amount` |

## 单次延迟分账请求

### data 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `mch_order_no` | 是 | 原支付订单号 |
| `alt_order_no` | 是 | 分账订单号；字母/数字/下划线，且每次唯一 |
| `alt_info` | 是 | 分账方列表 |
| `callback_url` | 是 | 异步通知地址，必须可直接访问且不可携带查询参数 |

### alt_info 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `alt_mch_no` | 是 | 分账方编号 |
| `alt_amount` | 是 | 分账金额（元） |

## 延迟分账查询

### data 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `alt_order_no` | 是 | 分账订单号 |

## 多次分账请求

### data 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `mch_order_no` | 是 | 原支付订单号 |
| `alt_order_no` | 是 | 分账订单号；字母/数字/下划线，且每次唯一 |
| `alt_this_amount` | 是 | 本次分账总额（元） |
| `alt_this_marketing_amount` | 否 | 营销分账金额 |
| `alt_info` | 是 | 分账方列表 |
| `callback_url` | 是 | 异步通知地址 |

### alt_info 参数

|------|------|------|
| `alt_mch_no` | 是 | 分账方编号 |
| `alt_amount` | 是 | 分账金额（元） |

| `alt_order_no` | 是 | 完结分账订单号 |

## 查询所有分账

### data 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `mch_order_no` | 是 | 原支付订单号 |

## 同步响应关注点

| 字段 | 说明 |
|------|------|
| `resp_code` | 受理结果，`A1000`=受理成功 |
| `resp_msg` | 受理描述 |
| `data.alt_main_status` | 主状态；受理成功后常见 `P0001` 处理中 |
| `data.biz_code` | 业务码 |
| `data.biz_msg` | 业务描述 |

同步成功通常只表示“已受理”，不表示最终分账已完成。最终状态仍要等异步通知或主动查询确认。
