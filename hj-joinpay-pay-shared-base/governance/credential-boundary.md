# 凭据使用边界

## 敏感凭据清单

| 凭据 | 字段 | 用途 | 存放位置 |
|------|------|------|---------|
| MD5 签名密钥 | `merchant_key` | MD5 签名计算 | 服务端配置文件 / 环境变量 |
| RSA 私钥 | `rsa_private_key` | RSA 请求签名 | 服务端配置文件 / 环境变量 |
| RSA 公钥 | `rsa_public_key` | RSA 响应验签 | 服务端配置文件 / 环境变量 |

## 安全规则

1. **严禁硬编码**：所有密钥通过环境变量或配置文件注入，不得出现在源代码中
2. **严禁前端暴露**：RSA 私钥和 MD5 密钥严禁写入前端代码或提交到代码仓库
3. **日志脱敏**：日志中禁止打印完整密钥、完整付款码
4. **联调专用**：开发和联调阶段使用联调专用密钥，不使用生产密钥

## 环境变量声明

| 环境变量 | 用途 | 敏感级别 |
|---------|------|---------|
| `JOINPAY_MERCHANT_NO` | 商户号 | 普通 |
| `JOINPAY_MERCHANT_KEY` | MD5 签名密钥 | **高敏感** |
| `JOINPAY_RSA_PRIVATE_KEY` | RSA 私钥 | **高敏感** |
| `JOINPAY_RSA_PUBLIC_KEY` | RSA 公钥 | 中等 |
| `JOINPAY_NOTIFY_URL` | 异步回调地址 | 普通 |
| `JOINPAY_BASE_URL` | 接口环境地址 | 普通 |

## 运行时值来源

以下值必须来自真实业务链路，不能由模型猜测：

| 值 | 来源 |
|----|------|
| `q5_OpenId` | 微信 OAuth 授权获取 |
| `qb_buyerId` | 支付宝授权获取 |
| `q6_AuthCode` | 用户展示的付款码 |
| `qa_TradeMerchantNo` | 汇聚后台报备管理 |
| `q7_AppId` | 微信开放平台申请 |
