# 状态与通知

二级商户入网包含申请单审核、商户状态、签约状态和异步通知四类状态处理。

## 申请单审核状态

| 状态 | 含义 | 处理建议 |
|------|------|----------|
| `P1000` | 已创建 | 等待审核流转 |
| `P2000` | 审核中 | 继续轮询或等待通知 |
| `P3000` | 已驳回 | 展示驳回原因；如有异议联系汇聚客服 |
| `P4000` | 申请通过 | 引导二级商户签约 |

审核分两段：系统机审先校验法人、证件、企业要素等合法性和一致性；通过后进入人工审核，主要审核经营场景材料。系统机审驳回时，通常需要用新的 `mch_order_no` 重新发起入网；如资料正确但被误判，可联系汇聚客服申请转人工。

## 审核类型

| 字段 | 状态值 | 含义 |
|------|--------|------|
| `audit_type` | `01` | 系统审核 |
| `audit_type` | `02` | 人工审核 |

## 商户状态

| 状态 | 含义 | 处理建议 |
|------|------|----------|
| `P1000` | 待签约 | 审核通过但合同未完成；引导签署或重签 |
| `P2000` | 已激活 | 入网完成，可进入正常业务流程 |
| `P3000` | 已冻结 | 通常为认证失败或风控限制；必要时修改结算信息 |
| `P4000` | 认证中 | 等待打款认证结果 |

补充流程资料强调：商户状态变为 `P2000` 已激活前，不能入账，也不能出款。实现可结算判断时，不要仅凭审核通过或签约完成放行。

## 签约状态

| 状态 | 含义 | 处理建议 |
|------|------|----------|
| `P1000` | 待签署 | 合同已创建，等待签署人处理 |
| `P2000` | 商户已签署 | 商户侧签署完成，等待平台侧或流程完成 |
| `P3000` | 已生效 | 签约完成，系统会进入打款认证 |
| `P4000` | 商户撤销 | 商户侧撤销，按业务需要重发 |
| `P5000` | 平台撤销 | 平台侧撤销，按业务需要重发 |
| `P6000` | 已拒签 | 签署人拒绝，需要重新发起签约 |

自动发起的电签未签约时通常表现为待签署，不会额外出现拒签状态；如果撤销后重新发起的电签被商户拒签，签约查询可能返回 `P6000`，且通常不会有异步通知，需要主动查询。

## 撤销结果

| 状态 | 含义 |
|------|------|
| 成功 | 撤销请求已处理成功 |
| 失败 | 撤销请求明确失败 |
| 未知 | 请求异常或超时，需查询确认最终状态 |

## 异步通知

入网、修改和签约完成类通知会 POST 到请求中的 `callback_url`。

| 处理项 | 要求 |
|--------|------|
| 验签 | 使用 API Gateway 响应/回调验签规则，排除 `sign` 和 `sec_key` |
| 解密 | 如返回敏感字段，使用商户私钥解密 `sec_key` 后再 AES 解密 |
| 幂等 | 按 `mch_order_no`、`trx_no`、`status` 或签约订单号去重 |
| 应答 | 业务处理成功返回 `success`；失败返回 `fail` 或非 success |
| 补发 | 未按正确格式应答时，平台会按间隔补发 |

签约状态变化通常不直接通过入网 `callback_url` 返回完整签约状态；签约完成后会进入打款认证，平台可通过商户状态变为 `P2000` 已激活或 `P3000` 已冻结间接判断认证结果。如需签署进度、签署人信息和链接，调用 `secondaryMchSign.query`。

## 常见处理

| 问题 | 处理 |
|------|------|
| 审核驳回 | 根据原因修正资料，使用新的 `mch_order_no` 重新发起；机审误判可联系汇聚客服转人工 |
| 签署人信息错误 | 待签署时先 `secondaryMchSign.revoke`，再 `secondaryMchSign.create` 传正确签署人 |
| 打款认证失败 | 调用 `secondaryMch.modify` 修改 `account_info`，系统会重新打款认证 |
| 一直待签约 | 检查签约短信或链接，引导签署；长时间未签可撤销后重发 |
| 已激活仍不能结算 | 确认商户状态 `P2000`、签约状态 `P3000`、结算账户认证成功和结算配置 |

## 推荐落库字段

| 字段 | 用途 |
|------|------|
| `mch_order_no` | 商户申请单号或签约订单号 |
| `trx_no` | 平台流水号 |
| `alt_mch_no` | 二级商户号 |
| `status` | 申请单、商户或签约状态 |
| `callback_raw` | 脱敏后的回调原文 |
| `last_notify_time` | 最近通知时间 |
| `notify_count` | 通知处理次数 |
