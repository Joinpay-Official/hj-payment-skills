# 字段与敏感信息

本文件只描述字段结构和敏感信息边界，不提供真实商户资料。

## 来源优先级

| 内容 | 优先级 |
|------|--------|
| 字段名、method、签名规则、请求结构 | 以二级商户 API 接口文档为准 |
| 入驻到可结算的操作流程 | 以全流程补充文档为补充 |
| 各商户类型字段必填口径 | 以字段整理补充文档为补充 |
| 文档冲突处理 | 回到 API 接口文档；必要时联系汇聚技术支持确认 |

## 商户类型差异

`secondaryMch.create` 常见商户类型：

| 商户类型 | `alt_merchant_type` | 说明 |
|----------|---------------------|------|
| 个人 | `10` | 需要职业类别；结算账户必须为借记卡 |
| 个体工商户 | `11` | 可使用借记卡或对公账户 |
| 企业 | `12` | 结算账户必须为对公账户 |

通用原则：姓名、手机号、身份证号、银行卡号、账号密码等个人或账户信息必须 AES 加密；图片类字段应先上传换取 `image_id`。

## 图片字段

资质图片需要先调用 `secondaryMchPics.uploadPic` 上传，获取 `image_id` 后再填入入网或修改接口。

| 图片字段 | 说明 |
|----------|------|
| `id_doc_copy` | 法人身份证人像页照片 |
| `id_card_national` | 法人身份证国徽页照片 |
| `trade_licence` | 营业执照图片 |
| `special_licence_one` / `special_licence_two` | 特殊资质 |
| `open_account_licence` | 银行账户证明 |
| `mp_compic` / `mp_authpic` | 公众号经营场景截图 |
| `mini_compic` / `mini_authpic` | 小程序经营场景截图 |
| `app_compic` | APP 经营场景截图 |
| `h5_compic` | H5 经营场景截图 |
| `door_photo` / `environment_photo` / `co_agreement` | 线下门店材料 |

## `mch_info`

商户基本信息。

| 字段 | 说明 | 敏感 |
|------|------|------|
| `login_name` | 登录名 | 否 |
| `alt_mch_name` | 二级商户全称 | 否 |
| `alt_mch_short_name` | 二级商户简称 | 否 |
| `alt_merchant_type` | 商户类型 | 否 |
| `busi_contact_name` | 联系人姓名 | 是 |
| `busi_contact_mobile_no` | 联系人手机号 | 是 |
| `bussiness_type` | 行业类别 | 否 |
| `province` / `city` / `county` | 经营地区 | 否 |
| `manage_scope` | 经营范围 | 否 |
| `manage_addr` | 经营地址 | 否 |

按商户类型：

| 字段 | 个体户 | 企业 | 个人 |
|------|--------|------|------|
| `mch_order_no` | 必填 | 必填 | 必填 |
| `login_name` | 必填 | 必填 | 必填 |
| `alt_mch_name` | 必填 | 必填 | 必填 |
| `alt_merchant_type` | `11` | `12` | `10` |
| `manage_scope` | 必填 | 必填 | 不适用 |
| `manage_addr` | 必填 | 必填 | 必填 |

## `id_card_info`

法人身份信息。

| 字段 | 说明 | 敏感 |
|------|------|------|
| `legal_person` | 法人姓名 | 是 |
| `phone_no` | 法人手机号 | 是 |
| `id_card_no` | 法人身份证号 | 是 |
| `id_card_valid_time_begin` / `id_card_valid_time_end` | 身份证有效期 | 否 |
| `id_doc_copy` / `id_card_national` | 身份证照片 `image_id` | 否 |
| `id_career` | 法人职业 | 否 |
| `beneficiary_owner` | 法人是否为受益人 | 否 |

身份证有效期长期时，补充资料建议使用 `2099-12-31`。个人商户需要传 `id_career`；个体户和企业通常不需要。

## `license_info`

营业执照和特殊资质信息。个人或小微场景可能按接口规则减少营业执照字段。

| 字段 | 说明 | 敏感 |
|------|------|------|
| `license_no` | 营业执照编号 | 否 |
| `license_expiry` | 营业执照有效期 | 否 |
| `trade_licence` | 营业执照图片 `image_id` | 否 |
| `special_licence_one` / `special_licence_two` | 特殊资质 `image_id` | 否 |

按商户类型：

| 字段 | 个体户 | 企业 | 个人 |
|------|--------|------|------|
| `license_no` | 必填 | 必填 | 不适用 |
| `license_expiry` | 必填 | 必填 | 不适用 |
| `trade_licence` | 必填 | 必填 | 不适用 |
| `special_licence_one` / `special_licence_two` | 特殊行业必填 | 特殊行业必填 | 不适用 |

特殊行业如教育、医疗等是否必传特殊资质，应以汇聚销售经理或最新审核要求为准。

## `account_type`

结算规则信息。

| 字段 | 说明 | 敏感 |
|------|------|------|
| `sett_mode` | 结算方式 | 否 |
| `sett_date_type` | 结算周期类型 | 否 |
| `risk_day` | 结算周期 | 否 |

常见取值：

| 字段 | 取值 |
|------|------|
| `sett_mode` | `1` 自动、`2` 手工、`3` 手工+D0、`4` 自动+D0 |
| `sett_date_type` | `1` 工作日、`2` 自然日、`3` 月结日 |
| `risk_day` | 与结算周期配合；T+1/D+1 通常为 `1`，月结时表示每月几号 |

## `account_info`

结算账户信息。

| 字段 | 说明 | 敏感 |
|------|------|------|
| `bank_account_type` | 结算账户类型 | 否 |
| `bank_account_name` | 银行账户名称 | 是 |
| `bank_account_no` | 银行账号 | 是 |
| `bank_channel_no` | 联行号 | 否 |
| `open_account_licence` | 银行账户证明 `image_id` | 否 |

按商户类型：

| 规则 | 个体户 | 企业 | 个人 |
|------|--------|------|------|
| `bank_account_type` | `1` 借记卡或 `4` 对公账户 | 必须 `4` | 必须 `1` |
| `bank_account_name` | 借记卡填法人姓名；对公填商户全称 | 商户全称 | 法人姓名 |
| `bank_channel_no` | 对公时必填 | 必填 | 不适用 |
| `open_account_licence` | 对公或审核要求时上传 | 必填 | 不适用 |

## `beneficiary_info_list`

受益所有人信息。当法人不是受益人时通常必传。

| 字段 | 说明 | 敏感 |
|------|------|------|
| `beneficiary_name` | 受益人姓名 | 是 |
| `beneficiary_no` | 受益人证件号 | 是 |
| `beneficiary_type` | 证件类型 | 否 |
| `beneficiary_time_begin` / `beneficiary_time_end` | 证件有效期 | 否 |
| `beneficiary_address` | 证件居住地址 | 是 |

补充字段口径：

| 条件 | 个体户 | 企业 | 个人 |
|------|--------|------|------|
| `beneficiary_owner=1` | 不填列表 | 不填列表 | 不填列表 |
| `beneficiary_owner=2` | 必填，最多 4 个 | 必填，最多 4 个 | 不支持 |

`beneficiary_address` 在补充资料中标为不加密；若项目安全策略更严格，可在不影响协议的前提下按敏感地址处理。

## `sales_info`

经营场景材料列表。

| `material_id` | 场景 | 常见 `material_type` |
|---------------|------|----------------------|
| `mp_proof` | 微信公众号 | `mp_name`、`mp_compic`、`mp_authpic` |
| `mini_proof` | 微信小程序 | `mini_name`、`mini_compic`、`mini_authpic` |
| `app_proof` | APP | `app_name`、`app_url`、`app_compic`、`app_account`、`app_password` |
| `h5_proof` | H5 | `h5_url`、`h5_compic`、`h5_account`、`h5_password` |
| `locallife_proof` | 线下门店 | `door_photo`、`environment_photo`、`co_agreement` |

`app_account`、`app_password`、`h5_account`、`h5_password` 属于敏感信息，应 AES 加密。

经营场景材料所有商户类型均必填，至少提供一组。`locallife_proof` 仅限特定本地生活或线下零售行业使用，例如企业电商本地生活、企业线下零售其他综合零售、个体工商户线下零售其他综合零售。

## `signer_info`

签署人信息选填。如果不传，默认发送给法人签署；如果需要非法人签署，则整组传入。

| 字段 | 说明 | 加密 |
|------|------|------|
| `signer_name` | 签署人姓名 | 是 |
| `signer_phone` | 签署人手机号 | 是 |
| `signer_card_type` | 证件类型，身份证固定 `1` | 否 |
| `signer_card_id` | 签署人身份证号 | 是 |

整组传入时四个字段都必填。

## 通用字段

| 字段 | 说明 |
|------|------|
| `callback_url` | 异步通知地址，选填 |
| `sec_key` | 有敏感信息时条件必填 |
| `sign` | 签名串，必填 |
| `sign_type` | 签名类型，RSA 固定 `2` |
| `rand_str` | 32 位随机字符串 |
| `method` | 如 `secondaryMch.create` |
| `version` | 通常 `1.0` |
| `mch_no` | 平台商户编号 |
