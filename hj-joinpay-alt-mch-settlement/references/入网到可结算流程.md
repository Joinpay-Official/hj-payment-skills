# 入网到可结算流程

分账方从创建到可结算必须完成三项，文档未要求强制顺序，但任一项缺失都可能导致结算失败：

1. 分账方信息添加并完成打款认证
2. 资质图片上传并通过审核
3. 协议签约完成

```text
商户平台 -> 汇聚支付 -> 分账方 -> 银行账户
```

## 1. 分账方信息添加

调用 `altmch.create` 提交基础信息、结算账户和法人或个人信息。V1.4.2 入网接口版本为 `1.1`，分账方添加无 AES 加密。汇聚会向分账方账户打款 `0.01` 元进行认证，认证结果通过异步通知返回。

| 要点 | 规则 |
|------|------|
| 登录名 | `login_name` 唯一，建议本地建立映射 |
| 主体类型 | `10`=个人，`11`=个体，`12`=企业 |
| 结算模式 | `1`=自动，`2`=手工，`3`=手工+D0，`4`=自动+D0 |
| 账户类型 | `1`=借记卡，`4`=对公账户 |
| 认证失败限制 | 每日最多 10 次，超次后当天不可再修改认证相关资料 |

## 2. 资质图片上传

调用 `altMchPics.uploadPic` 上传图片。图片审核通过通常无通知，审核不通过才异步通知。

| 主体 | 常见资料 |
|------|----------|
| 个人 | 身份证正面、身份证反面 |
| 个体 | 身份证正反面、营业执照、开户许可证 |
| 企业 | 身份证正反面、营业执照、开户许可证 |

图片要求：

- Base64 上送，单张不超过 2M
- 尺寸不小于 640 x 480
- JPG、PNG、BMP 格式
- 清晰无遮挡、无变形、不反光

## 3. 协议签约

支持两种签约方式。

| 方式 | 流程 | 注意事项 |
|------|------|----------|
| 内容签约 | 调 `altMchSign.querySignContent` 获取协议 -> 商户页面展示 -> 分账方同意 -> 调 `altMchSign.sign` 提交 | 商户需确保页面展示内容与获取的协议一致 |
| 页面签约 | 调 `altMchSign.getSignUrl` 获取 URL -> 跳转汇聚页面 -> 分账方签约 -> 接收异步回调 | 回调必须验签和幂等处理 |

签约状态可通过 `altMchSign.querySignRecord` 查询。

## 4. 可结算检查

发起 `altSettle.launch` 前至少检查：

| 检查项 | 通过条件 |
|--------|----------|
| 信息认证 | `auth_status` 为认证成功 |
| 资料审核 | 资质图片已上传且审核通过 |
| 协议签约 | 签约已完成 |
| 账户余额 | `altAccount.get` 返回可结算余额足够 |
| 结算模式 | 分账方配置支持当前结算方式，如手工或 D0 |

## 修改规则

### 文字信息

| 阶段 | 可修改 | 不可修改 |
|------|--------|----------|
| 未上传图片 | 全部 | 无 |
| 图片审核不通过 | 全部文字和图片 | 无 |
| 图片审核通过 | 联系人、结算、银行卡信息 | 全称、法人、身份证、营业执照 |

### 图片信息

| 场景 | 规则 |
|------|------|
| 审核通过后 | 身份证反面、营业执照默认不可改 |
| 特殊修改机会 | 可有 1 次特殊修改机会，冷却期 180 天 |

### 固定不可改信息

| 主体 | 固定不可改 |
|------|------------|
| 企业 | 营业执照编号 |
| 个人 | 身份证号 |

## 要素校验

| 类型 | 校验要素 |
|------|----------|
| 个人或个体户对私打款认证 | 户名 + 账号 |
| 企业对公打款认证 | 户名 + 账号 + 联行号 |
| 个人鉴权 | 姓名 + 身份证 |
| 企业鉴权 | 企业全称 + 营业执照 + 法人姓名 + 法人身份证 |

## 特殊字符限制

参数值应避免包含影响签名、解析或风控的特殊字符，尤其是：

```text
=|%<
```
