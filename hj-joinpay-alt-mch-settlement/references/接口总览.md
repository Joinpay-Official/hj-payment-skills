# 分账方入网与结算接口总览

分账方入网与结算接口使用 `/allocFunds` JSON 协议，生产入口为：

```text
https://www.joinpay.com/allocFunds
```

## 公共请求

| 参数 | 必填 | 说明 | 是否参与签名 |
|------|------|------|--------------|
| `method` | 是 | 接口方法名，如 `altmch.create`、`altSettle.launch` | 是 |
| `version` | 是 | 版本号；V1.4.2 分账方添加和结算接口当前使用 `1.1` | 是 |
| `data` | 是 | 业务参数 JSON 对象或最终上送的 JSON 字符串 | 是 |
| `rand_str` | 是 | 32 位随机串 | 是 |
| `sign_type` | 是 | `1`=MD5，`21`=RSA | 是 |
| `mch_no` | 是 | 商户编号，通常为 15 位 | 是 |
| `sign` | 是 | 请求签名 | 否 |
| `aes_key` | 否 | V1.4.2 分账方添加无 AES 加密；如响应或存量接口出现，签名时排除 | 否 |

签名规则见 [签名规则.md](签名规则.md)。V1.4.2 分账方入网文档说明签名时排除 `sign`/`aes_key`；`altmch.create` 新接入示例不使用 AES 加密。

## 接口列表

| 接口 | method | 用途 | 核心请求字段 | 响应或后续重点 |
|------|--------|------|--------------|----------------|
| 分账方添加 | `altmch.create` | 新增分账方并触发打款认证 | `login_name`、`alt_mch_name`、`alt_merchant_type`、`sett_mode`、`sett_date_type`、`risk_day`、`bank_account_type` | 保存分账方编号和认证状态 |
| 分账方修改 | `altmch.modify` | 修改分账方文字资料、结算账户等 | 登录名或分账方编号、可修改字段 | 审核阶段决定可改范围 |
| 分账方查询 | `altmch.query` | 按登录名或分账方编号查询 | `login_name` 或 `alt_mch_no` | `auth_status`、`approve_status` 等状态 |
| 图片上传 | `altMchPics.uploadPic` | 上传资质图片 | 图片类型、Base64 图片内容 | 图片审核不通过才异步通知 |
| 图片修改 | `altMchPics.modifyPic` | 修改资质图片 | 图片标识、Base64 图片内容 | 受审核通过后修改规则限制 |
| 图片查询 | `altMchPics.queryPicsInfo` | 查询已上传图片信息 | 分账方标识 | 图片审核状态和图片信息 |
| 获取协议内容 | `altMchSign.querySignContent` | 内容签约前获取协议文本 | 分账方标识 | 商户自建页面展示协议 |
| 提交内容签约 | `altMchSign.sign` | 分账方在商户页面确认签约 | 分账方标识、签约确认信息 | 保存签约结果 |
| 获取页面签约 URL | `altMchSign.getSignUrl` | 获取汇聚签约页地址 | 分账方标识、回调地址 | 跳转汇聚页面签约，等待回调 |
| 签约状态查询 | `altMchSign.querySignRecord` | 查询分账方签约状态 | 分账方标识 | 判断协议签约是否完成 |
| 手工结算 | `altSettle.launch` | 发起分账方结算 | `alt_mch_no`、`settle_amount`、`mch_order_no`、`callback_url` | 同步受理，异步确认结果 |
| 结算查询 | `altSettle.get` | 查询手工结算结果 | `mch_order_no` | 结算订单状态 |
| 自动结算查询 | `altSettle.getAutoSettle` | 查询自动结算记录 | `settle_date`、`alt_mch_no` | 自动结算状态 |
| 账户余额查询 | `altAccount.get` | 查询分账方账户余额 | `alt_mch_no` | 担保余额、当日收款、可结算余额、总余额 |

## 分账方添加核心字段

| 字段 | 说明 |
|------|------|
| `login_name` | 分账方登录名，必须唯一 |
| `alt_mch_name` | 分账方全称 |
| `alt_mch_short_name` | 分账方简称，最长 20 字符 |
| `alt_merchant_type` | `10`=个人，`11`=个体，`12`=企业 |
| `phone_no` | 法人手机号 |
| `legal_person` | 法人姓名；V1.4.2 分账方添加无 AES 加密 |
| `id_card_no` | 法人证件号；V1.4.2 分账方添加无 AES 加密 |
| `id_card_expiry` | 证件有效期，格式 `yyyy-MM-dd`，为空时系统按长期处理 |
| `busi_contact_name` | 业务联系人姓名 |
| `busi_contact_mobile_no` | 业务联系人手机号 |
| `license_no` | 企业、个体工商户必填营业执照号 |
| `license_expiry` | 营业执照有效期，格式 `yyyy-MM-dd`，为空时系统按长期处理 |
| `manage_scope` | 经营范围 |
| `manage_addr` | 经营地址 |
| `sett_mode` | `1`=自动，`2`=手工，`3`=手工+D0，`4`=自动+D0 |
| `sett_date_type` | `1`=工作日，`2`=自然日，`3`=月结日 |
| `risk_day` | 风险预存期或结算日；月结日范围 1-28 |
| `bank_account_type` | `1`=借记卡，`4`=对公账户 |
| `bank_account_name` | 结算账户名；企业对公时需与分账方全称一致；V1.4.2 分账方添加无 AES 加密 |
| `bank_account_no` | 结算银行账号；V1.4.2 分账方添加无 AES 加密 |
| `bank_channel_no` | 联行号，对公账户必填 |
| `notify_url` | 分账方入网认证异步通知地址 |

## 图片接口要求

| 项 | 要求 |
|----|------|
| 请求入口 | `https://upload.joinpay.com/allocFunds` |
| 图片内容 | Base64 |
| 单张大小 | 不超过 2M |
| 图片尺寸 | 不小于 640 x 480 |
| 图片格式 | JPG、PNG、BMP |
| 画面质量 | 清晰、无遮挡、无变形、不反光 |

常见必传资料：身份证正反面；企业和个体通常还需营业执照、开户许可证。

## 协议签约方式

| 方式 | 适用场景 | 接口链路 |
|------|----------|----------|
| 内容签约 | 商户自建签约页面 | `altMchSign.querySignContent` -> 展示协议 -> `altMchSign.sign` |
| 页面签约 | 使用汇聚签约页面 | `altMchSign.getSignUrl` -> 跳转汇聚页面 -> 异步回调签约结果 |
