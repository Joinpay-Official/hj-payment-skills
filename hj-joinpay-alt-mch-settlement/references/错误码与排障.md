# 错误码与排障

本文件汇总分账方入网与结算常见响应码、业务码和排障优先级。完整错误信息以汇聚返回为准。

## 公共响应码

| `resp_code` | 含义 | 处理建议 |
|-------------|------|----------|
| `A1000` | 受理成功 | 继续等待异步通知或主动查询最终状态 |
| `A2000` | 受理失败 | 根据 `resp_msg` 和业务码修正参数后重试 |
| `A3000` | 受理未知 | 不要直接判失败，先主动查询 |

## 结算状态

| `order_status` | 含义 | 处理建议 |
|----------------|------|----------|
| `P1000` | 交易成功 | 记录终态，幂等返回成功 |
| `P2000` | 交易失败 | 记录失败原因，必要时查余额、分账方状态和结算配置 |
| `P3001` | 处理中 | 保持处理中，等待通知或轮询查询 |

## 分账方状态

| 字段 | 状态 | 含义 |
|------|------|------|
| `auth_status` | `R4001` | 未认证 |
| `auth_status` | `R4002` | 认证中 |
| `auth_status` | `R4003` | 认证失败 |
| `auth_status` | `R4004` | 认证成功 |
| `approve_status` | `P0001` | 未审批 |
| `approve_status` | `P1000` | 审批通过 |
| `approve_status` | `P2000` | 审批不通过 |

## 特定业务码

| 场景 | 业务码 | 含义或方向 |
|------|--------|------------|
| 结算请求 | `B104001` | 无此分账方 |
| 结算请求 | `B104005` | 金额不足 |
| 结算查询 | `B104010` | 记录不存在 |
| 账户查询 | `B105001` | 无此分账方 |

## 常见问题

| 现象 | 优先检查 |
|------|----------|
| 参数或签名错误 | 商户号、密钥、公私钥、`sign_type`、请求地址、JSON 原文是否一致 |
| RSA 签名失败 | `sign_type` 是否为 `21`，算法是否按 V1.4.2 使用 `MD5withRSA`，请求签名值是否直接返回 Base64 文本 |
| 误报敏感字段解密失败 | V1.4.2 `altmch.create` 无 AES 加密，确认是否误传 `aes_key` 或把字段按旧版加密 |
| 入网字段不生效 | 分账方添加的回调字段是 `notify_url`，不是结算接口使用的 `callback_url` |
| MD5 签名失败 | 待签串末尾是否拼接 `&key=商户密钥` |
| 回调验签失败 | 是否排除 `sign` 后按字典序拼 `key=value&key=value` |
| 分账方认证失败 | 打款认证要素是否正确，是否超过每日 10 次限制 |
| 图片审核不通过 | 图片是否清晰、无遮挡、无变形、不反光，尺寸和格式是否符合要求 |
| 签约后仍不可结算 | 主动查询分账方、图片和签约状态，确认三项均完成 |
| 结算失败 | 查分账方状态、可结算余额、结算模式、`settle_fee` 是否超 1% |

## 商用配置来源

| 配置 | 获取位置 |
|------|----------|
| 商户编号 | 商户后台首页 -> 账户信息 |
| 商户密钥 | 商户中心 -> 密钥管理 |
| RSA 公私钥 | 商户生成公私钥并上传公钥至汇聚，验签使用汇聚平台公钥 |

## 安全与日志

- 不在日志中输出商户密钥、私钥、银行卡号、身份证号明文。
- 回调原文可脱敏保存，用于排查签名和状态问题。
- 对 `A3000`、网络超时和处理中状态使用查询补偿，不靠重复提交同一订单解决。
